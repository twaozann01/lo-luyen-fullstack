Thêm câu hỏi mới

Toàn bộ nằm trong một file index.html, không phụ thuộc thư viện ngoài. Câu hỏi ở mảng BANK — thêm câu = nối một object vào mảng đó. Chủ đề và mức tự xuất hiện trong bộ lọc, không cần khai riêng. 

{
  id: 'fe-09',                  // duy nhất, dùng làm khoá lưu tiến độ
  section: 'fe',                // khoá trong SECTIONS
  topic: 'React core',          // tự gom thành bộ lọc chủ đề
  level: 'trung bình',          // dễ | trung bình | khó
  multi: false,                 // true = nhiều đáp án đúng
  q: 'Nội dung câu hỏi (cho phép thẻ HTML)',
  code: 'đoạn mã kèm theo — bỏ trống nếu không cần',
  options: [{ id: 'a', text: '...' }, { id: 'b', text: '...' }],
  correct: ['b'],               // mảng id đáp án đúng
  why: `HTML giải thích — hiện trong hộp thoại`,
  followups: [{ q: 'Câu hỏi phụ', a: 'HTML câu trả lời' }],
}
Chuyển tiến độ sang máy khác

Tiến độ lưu trong trình duyệt của từng máy. Muốn mang sang máy khác thì chép chuỗi dưới đây rồi dán vào ô tương ứng ở máy kia.
