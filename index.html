Thêm câu hỏi mới

Trang này đọc từ mảng BANK ngay trong file. Thêm câu = nối một object vào mảng đó, không phải sửa gì khác. Chủ đề và mức độ tự xuất hiện trong bộ lọc, không cần khai riêng. Muốn mở phần mới (SQL, DevOps, System Design) thì thêm khoá vào SECTIONS. 

{
  id: 'fe-09',                  // duy nhất, dùng làm khoá lưu tiến độ
  section: 'fe',                // khoá trong SECTIONS
  topic: 'React core',          // tự gom thành bộ lọc chủ đề
  level: 'trung bình',          // dễ | trung bình | khó
  multi: false,                 // true = nhiều đáp án đúng
  q: 'Nội dung câu hỏi (cho phép thẻ HTML)',
  code: 'đoạn mã kèm theo — bỏ trống nếu không cần',
  options: [
    { id: 'a', text: '...' },
    { id: 'b', text: '...' },
  ],
  correct: ['b'],               // mảng id đáp án đúng
  why: `HTML giải thích — dùng <figure class="dg"> cho sơ đồ`,
  followups: [
    { q: 'Câu hỏi phụ hay bị hỏi tiếp', a: 'HTML câu trả lời' },
  ],
}
Chuyển tiến độ sang máy khác

Tiến độ lưu trong trình duyệt của từng máy. Muốn mang sang máy khác thì chép chuỗi dưới đây và dán vào ô tương ứng ở máy kia.
