# Lò Luyện Fullstack

Trang trắc nghiệm ôn phỏng vấn Front-end / Back-end, dựng từ chính dự án thật
(React + Vite + TanStack Query + Zustand ở FE; NestJS + Prisma + PostgreSQL ở BE).

**Xem tại:** https://twaozann01.github.io/lo-luyen-fullstack/

## Có gì

- Câu hỏi trắc nghiệm một hoặc nhiều đáp án, chấm ngay
- Đảo thứ tự câu và đảo thứ tự đáp án — tránh học vẹt "đáp án là câu B"
- Lọc theo phần / chủ đề / mức độ / trạng thái (chưa làm · từng sai · đã đúng)
- Tìm kiếm không dấu
- Mỗi câu có giải thích dài kèm sơ đồ luồng, và các câu hỏi phụ hay bị hỏi tiếp
- Tiến độ lưu trong trình duyệt; có ô chuyển tiến độ sang máy khác

## Thêm câu hỏi

Toàn bộ nằm trong một file `index.html` duy nhất, không phụ thuộc thư viện ngoài.
Câu hỏi nằm ở mảng `BANK` — thêm câu chỉ việc nối một object vào mảng đó.
Schema đầy đủ ghi ở cuối trang.
